## Перенос проекта на ноутбук — Git + GitHub

scande хочет продолжить работу над сайтом за ноутбуком. Выбрал Git + GitHub (не облако, не флешку),
репозиторий **приватный** (в `информация/` лежит пароль к полке референсов).

### Что сделано локально

- `git init -b main` в `C:\проекты\rz.74`, ветка `main`, первый коммит `57831f8`, 58 файлов.
- Состав репозитория: `наш сайт/` + `сам сайт/` + `.workbuddy-ai/memory/`. Исключены `_podbor/`,
  `модель/` (пустая), `информация/` (методичка + пароль).
- Локальная идентичность: `user.name=scande`, `user.email=scande@users.noreply.github.com`
  (заменить на реальный GitHub-логин, когда scande его назовёт).
- `core.quotepath false` — чтобы кириллические имена папок читались в `git status`.

### ГРАБЛИ: PortableGit переписывал переводы строк

- В `.../PortableGit/versions/1.2.0/etc/gitconfig` стоит `core.autocrlf=true` → git предупреждал
  «LF will be replaced by CRLF» и при следующем касании переписал бы файлы сайта.
- Лечение: `.gitattributes` с `* text=auto eol=lf` + локальный `core.autocrlf=false`.
  Проверка: `grep -c $'\r' "наш сайт/index.html"` → 0.
- **На ноутбуке после клонирования проверить то же самое** — если там PortableGit с autocrlf=true,
  а `.gitattributes` в репозитории есть, всё будет ок, но убедиться стоит.

- На ноутбуке тоже нужен установленный WorkBuddy AI.
