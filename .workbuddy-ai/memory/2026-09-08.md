- Габарит: **22.74 × 10.00 × 28.49 мм**.
- **Главная проблема**: в файле НЕТ готовых сеток. `BrepFace.getMesh()` для всех 410 Brep возвращает null, `rhino.Mesh.createFromBrep` в WASM-сборке rhino3dm 8.32.2 отсутствует, Rhino на машине не установлен.
- **Решение — свой триангулятор** `модель/3dm2obj.js` (чистый Node + rhino3dm):
  1. граница грани = обход тримов петли (`face.loops` → `.trims()` → `edgeIndex` → ребро → `tryGetPolyline()` или `toNurbsCurve()`), тримы с `edgeIndex = -1` (вырожденные) пропускать;
  2. **грань = плоская проверяется по факту**: отклонение точек контура от средней плоскости < 0.8% от размера. Это надёжнее `Surface.isPlanar()` — у огранённых камней он часто врёт;
  3. плоская грань → триангуляция ушами (ear clipping), subdivided не нужен;
  4. кривая грань → ear clipping в средней плоскости + 4-ное дробление (не больше 3 уровней, не больше 256 треугольников на грань) + посадка вершин на поверхность (поиск ближайшего UV по сетке 18² + уточнение Ньютоном через конечные разности);
  5. замкнутая поверхность без границы (тор/сфера) → сетка по UV-домену.
- Первая версия дала 1.35 млн треугольников (278 МБ) — взрыв из-за subdivision на гранях камней. После правила «плоскость по факту»: **109 017 треугольников** (металл 86 667 / камни 22 350), 22 МБ.

## Цифры мельче букв — причина и лечение (20:40)

- **Причина:** у Cormorant цифры по умолчанию **старинные (oldstyle)**. Замер по шрифту: прописная «H» = 625 единиц, а «0/1/2» = 396–412, при этом «3,5,7,9» ещё свисают под базу на 275. То есть рост цифры ≈ 65 % от буквы. Рядом с капсом это читается как «цифры намного меньше слов».
- **Лечение:** `font-variant-numeric: lining-nums` + `font-feature-settings: "lnum" 1` на `body`. Фича `lnum` в шрифте ЕСТЬ (проверено fontTools: в GSUB есть lnum, tnum, frac, dnom, numr).
- Важно: цифры в Cormorant тянутся из **latin**-поднабора Google Fonts, в cyrillic-поднаборе цифр вообще нет. Проверять надо именно latin-файл.
- Как проверять любую проблему «буква/цифра кривая»: `pip install fonttools brotli` в venv `C:\Users\оля на параше\.workbuddy-ai\binaries\python\envs\default`, скачать woff2 с fonts.gstatic.com и мерить BoundsPen.
- Слово «украшения» в hero было рукописным (`.hand` = Caveat) — заменил на `.gold`, теперь это шрифт заголовка. Класс `.hand` в HTML больше не используется (CSS оставил про запас).

## Плавный скролл — Lenis (21:58)

- Поставил **Lenis 1.1.14**, файл лежит локально: `наш сайт/vendor/lenis.min.js` (12.8 КБ) — интернет сайту не нужен. Подключён до `script.js`. Глобальная переменная `Lenis` (экспорт `globalThis.Lenis = L`).
- **Почему Lenis, а не самописный transform-скролл:** Lenis не подменяет скролл трансформом, а каждый кадр подтягивает НАСТОЯЩУЮ позицию (`window.scrollTo`). Поэтому `position: sticky` (hero, `.sv__sticky`, сцена «работы») продолжает работать. Трансформ-вариант убил бы все липкие блоки.
- Интеграция в `script.js`:
  - инициализация после `reduced`/`fine`, с проверкой `typeof Lenis !== 'undefined'`; при `prefers-reduced-motion` не включается;
  - `duration: 1.25`, `easing: t => Math.min(1, 1.001 - 2**(-10t))`, `smoothWheel: true`, `syncTouch: false`;
  - `function frame(t)` → первым делом `if (lenis) lenis.raf(t)` (иначе ничего не едет);
  - якоря: `lenis.scrollTo(top, { duration: 1.7 })` вместо `window.scrollTo({behavior:'smooth'})`.
- CSS в styles.css: стандартный блок Lenis (`html.lenis, html.lenis body {height:auto}` и т.д.).
- На `.drawer__panel` повесил `data-lenis-prevent`, чтобы страница не ехала под открытой шторкой.
- **Где крутить плавность:** `duration` в конструкторе. Больше — более «ватный», меньше — отзывчивее.
- **Настройки скопированы с augen.pro (22:00)** — эталон scande. У них Lenis 1.0.39, вызов в бандле `/_nuxt/entry.C4JQNA6F.js`:
  `new Lenis({ duration: 0.8, easing: i => 1 - Math.pow(1 - i, 4) })`, всё остальное по умолчанию.
